# DME 删除自己的消息

批量删除时，纯文本直接双向删除；符合条件的媒体先替换成占位图再删除。回复 `.dme` 删除单条消息或整组媒体时，保留先替换再删除的流程，纯文本也会尝试替换。

| 用法 | 范围 |
| --- | --- |
| `.dme N` | 当前聊天最近 N 条自己的消息 |
| `.dme 999999` | 当前聊天可扫描到的自己的消息 |
| 回复 `.dme` | 自己的单条消息或整组媒体 |
| 回复 `.dme -r` | 回复位置至命令之前，仅自己的消息；起点可以是他人的消息 |
| `.dme -a N` / `.dme --all N` | 显式跨聊天，含归档，选择最新 N 条自己的消息 |
| `.dme -k 关键词` | 当前聊天全部匹配的自己的历史消息 |
| `.dme -a -k 关键词` | 全部对话（含归档）匹配的自己的历史消息 |

`-k`（或 `--keyword`）后整段作为一个关键词，按不区分大小写的连续文字包含匹配，支持中文、正文和媒体说明；不使用正则表达式，也不保存自动清理规则。全局参数必须放在 `-k` 前，关键词不能与数量、回复、`-r` 混用。例如 `.dme -k 测试账号`、`.dme -a -k example.com`。关键词命中相册的一条消息时，只删除命中项，不扩展到未匹配项。

为避免 Telegram 分词搜索漏掉连续文字包含匹配，关键词模式分页检索自己的全部历史消息，再在本地匹配；没有扫描条数或会话数截断，因此历史较多时搜索仍会耗时。全局模式先收集普通和归档文件夹的会话，再逐一搜索。仅扫描当前账号仍可访问的历史，读取失败会统计并报告，不能保证覆盖已经退出或不可访问的对话。

原有全局**数量模式**普通/归档各最多扫描 500 个会话，每会话最多 80 条；当前聊天数量模式持续分页，直到数量达到或历史耗尽。关键词模式不使用这些限制。

仅处理命令开始前的消息，拒绝跨聊天回复和冲突参数。转发、贴纸、网页预览及超过 48 小时的消息不替换，直接尝试删除；替换失败也继续尝试删除并报告。成功替换的媒体间隔 1.5 秒，一批替换完成后等待 1 秒；纯文本批量删除不经过这些替换等待。取消后不继续修改消息。能否删除由 Telegram 权限决定，替换不能保证第三方未留存原内容。

默认占位图随程序发布，嵌入二进制。配置沿用 `data/dme.json`；已有 `.d → dme` 别名保留。

测试使用模拟 Telegram RPC，包括真实 TL 编解码；不以真实历史聊天作为删除测试数据。
