- [x] 审查核心运行缓存、并发和状态写入，补回归并修复证据明确的问题。

- [x] Docker 使用相同正式 Linux 二进制和 BuildKit 层缓存，保留源码构建路径。
- [x] 验证脚本参数、版本注入、六平台产物/校验及工作流结构。
- [x] 全仓库单元、集成、race、覆盖率、构建和静态检查，检查更新兼容 0.x→1.0.0。
